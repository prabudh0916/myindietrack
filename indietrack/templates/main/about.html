System Architecture & RDBMS Design

IndieTrack is architected as a secure, modular monolith following 3-Tier Enterprise Architecture, adhering to strict Third Normal Form (3NF) relational principles with referential integrity constraints, automated audit trails, and multi-cloud resilience:

Relational Database (Azure SQL)

  • Normalized 3NF relational schema across 8 entities (Users, Profiles, Songs, Releases, Campaigns, Metrics, Assets, AuditLogs).
  • Database Views: CampaignPerformanceView calculating zero-division-safe CTR, CPC, and CPS metrics.
  • Transact-SQL Stored Procedure: sp_LaunchReleaseCampaign enforcing atomic multi-step transactions with BEGIN TRANSACTION, TRY...CATCH, and automatic ROLLBACK.
  • Non-clustered indexes on high-frequency filters, composite joins, and foreign keys.

Application Security Controls

  • Secure Scrypt / PBKDF2 password hashing via werkzeug.security.
  • Cross-Site Request Forgery (CSRF) protection on all state-changing POST forms via Flask-WTF.
  • Spreadsheet Formula Injection (CWE-1236) defense on CSV exports, escaping =, +, -, @, \t, \r prefixes.
  • Magic-bytes MIME sniffing on file uploads with maximum size enforcement and private Azure Blob storage.
  • Server-side resource ownership checks on every request (cross-user data isolation).
